# 智耕小塔｜智在家鄉 AI 農業助理平台

這是可直接上傳 GitHub Pages 的新版網站。

## 特色
- 放大首頁主標：「智在家鄉 × 都市小農 × AI農業助理」
- App Demo：首頁、AI、紀錄、警示、控制、Open Data
- 即時影像監控 Demo
- AI 影像分析示意
- 產品圖片、功能海報、漫畫解說
- 適合智在家鄉、都市小農、校園食農教育、小農地智慧化展示

## GitHub Pages 上傳方式
1. 解壓縮 zip
2. 將內容上傳到 `farm` repository
3. 覆蓋原本的 `index.html`、`style.css`、`script.js` 與 `assets`
4. GitHub Pages 會自動更新
